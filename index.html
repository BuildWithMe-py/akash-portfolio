    AI & vibe coding
    

    My focus is learning to use AI tools as part of a disciplined software-development workflow: define the problem, provide useful context, guide the model, inspect the generated code, and verify that the result works.
    


    
  
    
    
    What vibe coding means to me
    
    FOUNDATION
  
    
  
    Vibe coding is an AI-assisted way to build software by describing the outcome in natural language and iterating with an AI coding tool. It can speed up implementation, but it does not remove the developer's responsibility for requirements, code understanding, testing, security and maintenance.
